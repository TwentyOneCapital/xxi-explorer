About this explorer

This is Twenty One Capital's Bitcoin explorer. It shows the Bitcoin blockchain and mempool from Twenty One's own Bitcoin node, together with the company's disclosed reserve addresses, which it reads from twentyonecapital.com.

Software

This explorer is derived from the source code for mempool.space, published by The Mempool Open Source Project®. Twenty One Capital, Inc. modified it in 2026 to add its branding, its reserve addresses and company news, and to run entirely on its own infrastructure.

The complete source code of the version running here is available at github.com/TwentyOneCapital/xxi-explorer. This build: v{{ packetJsonVersion }} [{{ frontendGitCommitHash }}].
